# The optimizer only plans builds the game allows: level-gated ranks, paid stigmas, automatic stigma tiers, currencies

Derived from the Global client export (`research/progression_connections_2026-10-05.md` in the level planner repo, cross-checked against its independently generated `progression/data.json`: level budgets and every rank gate agree). Only derived facts ship: `app/aion2c/data/client_progression.json`, written by `python -m aion2c.data.client_export` (`build_progression`); a guard test rebuilds it from the export when one is present. Client version is unverified (`client_version: null`).

## Rules and evidence

- **Level-gated rank acquisition.** `SkillAcquireData.NeedCharacterLevel` per rank. Example (our `flame-scattershot`, client id 15010000): rank 8 needs level 23, rank 10 level 29. `progression.max_rank_at_level` caps what the allocator can buy (`budget._pool`). A rank a manual or imported build already holds above its gate is never capped: `progression.legality_issues` reports it and the optimizer adds it to the build's warnings. Skills without acquisition rows (procs, charge children) have no gate rather than a guessed one.
- **Stigma rank 1 costs 1 point** (`CostStigmaPoint` 1/2/4/8 in blocks of five, 75 to rank 20, rank 1 included). `allocate_points` first buys rank 1 of every equipped stigma that has no bought rank, then spends the rest; with a stigma budget the optimizer equips no more stigmas than `held + points`. `effective_rank` is unchanged on purpose: it is what the simulator plays, and an equipped stigma with no entry still plays at rank 1 (as entered). The planned-rank estimate (`_planned_stigma_rank`) now prices rank r as `sum(STIGMA_POINT_COST[:r])`.
- **Stigmas need the unlock**: Ascension grade 3 (`NeedAscensionGrade` on every stigma rank 1) plus the faction quest (`GlobalSetting` AQ1602010 / AQ2602010); the level gate on every stigma row is 22. New optional `CharacterBuild.stigma_unlocked` (`true` / `false` / `None`). `None` infers: a held stigma rank proves it (`basis: "ranks"`), otherwise level >= 22 (`basis: "level"`, weak: a level alone does not prove the quest). Level-only inference is reported (`webapi.level_progression`, an optimizer warning), never silent.
- **Specialty slots** (selectable Mastery slots) open at skill ranks 8/12/20: `SpecializedSkillSlot.UnlockSkillLv`, `bUserEditSlot` true. Their confidence is now `confirmed` (it was `estimated`, from a guide). Options unlock per `SpecializedSkillParts` (8/8/8/12/16 for Sorcerer mastery), a separate table.
- **Stigma tiers are automatic.** The five Stigma slot rows have threshold 0, `bShowSlot` false, `bUserEditSlot` false, and Parts use `InitEquipSlotType`: the tier options at stigma ranks 5/10/15/20 activate on their own. This replaces the unverified 1/1/2/3 rule of ADR 0002 (a stigma used as many tiers as mastery slots were open): `specs.slot_room` returns every available option for a stigma. The simulator, `choose_specs`, and the allocator's `dps_at` all use it.
- **Level budgets** are one `Exp` row (cumulative, never summed): skill, stigma, stigma slots, DaevanionCrystal (level 45: 203 / 29 / 4 / 136). They are a levelling baseline, not an imported character's wallet (quest and dungeon rewards come on top; BattleCrystal is a separate pool). They replace the hard-coded 22/27/32/37 stigma-slot fallback and are exposed by `progression.level_budget` and `webapi.level_progression`. A build whose `skill_points` / `stigma_points` is `None` still means "ranks as entered": nothing is rewritten from the level.
- **Daevanion currencies.** Every class's last board (Azphel, level 45) is paid in BattleCrystal (`DaevanionBoard.CostPointType`); Nezekan, Zikel, Vaizel and Triniel use DaevanionCrystal. `DaevanionBoard.currency` (`"daevanion"` / `"battle"`, guard-tested against the derived file for all eight classes). `daevanion_points` never pays for a battle board; an optional separate `battle_points` budget does, and without it Azphel is not planned (nodes a character already has are kept). `daevanion.take_path` applies both budgets; an exhausted currency stops only its own nodes. Azphel's nodes are almost all PvP stats, so the DPS-greedy planner rarely wants them anyway.

## Not claimed

Quest and dungeon point rewards, the faction Daevanion unlock quests (HQ1102060 / HQ2102065), and prerequisite/item-cost lists (empty in this export, so not modelled) are not part of the budgets. Korea caps are not inferred from Global tables.
