# Build optimizer vs community builds, v3 (2026-10-03, after buff recognition, bonus ranks, per-hit damage)

Same test and formula as v2 (`build_validation_v2.md`): level-45 Global build per class, `compare_playstyles`, boss playstyle, versus `community_builds/consensus.json` (boss set). Score = 50% stigma overlap + 35% rotation shape + 15% stat ranking. Raw runs: `D:\Aion2\.firecrawl\v3\` (`before_*` = engine at the start of this task, `a3default_*` = now with `Stats()`, `a3baseline_*` = now with the baseline L45 profile; scorer `score.py`, overlap `ov.py`).

## What changed in the engine (items 1 and 2 plus routed gaps)
1. **Stat-buff recognition.** `search._is_buff` only counted self statuses with `dmg_mult > 1`. It now values a skill by its simulated kind of effect: stat mods (attack, damage boost, combat speed, CDR, crit chance, crit damage, weighted for ordering only), permanent auras, PROC window openers, and self tick/proc buffs (Flame Blessing). These sort first in every seed (`_seeds`, `_heuristic_priority`). The stigma chooser (`build_optimizer._best_stigma_dps`) scores a set by the best of: the greedy priority, the priority with each never-cast stigma moved to the front, and the priority with each cast stigma removed (a set is never worse than the same set with one stigma left uncast). Forcing-to-front by hand is no longer needed.
2. **Bonus ranks.** `models.total_rank` = skill-point rank (cap 10 bought) + Daevanion skill nodes (+1 each, max +4, boards unlocked at the level) + `CharacterBuild.bonus_ranks[skill_key]` (Arcana / Soul Binding, entered by the user, default `{}`, serde back-compat), clamped to the region cap (Global 20). The simulator, `specialties.skill_rank`, `search._skill_numbers` and `rotation.cooldown_of` all use it, so rank 12/16/20 specialty options and slots unlock on it. `plan_daevanion` now values a Daevanion skill node by the best average over taking 1..4 more nodes including the specialty each rank unlocks (a rank-12 option is two nodes away).
3. **Routed engine gaps.** (a) a PROC owner's own specialties now run (on-hit statuses, reset-on-crit such as Heart Gore rank 16); a proc still cannot re-trigger itself. (b) `StatusTrigger.requires_status`: a proc/trigger that only fires while a (target) status is up. (c) `SkillRule.requires_spec = (owner, option)`: a chain follow-up or proc that exists only while that specialty option is chosen and unlocked. (d) force-crit plus reset-on-crit makes a cooldown skill castable every time (test). Class agents wire the data for (b) and (c).
4. **Per-hit damage.** Evidence: the client text reads "119.5% ATK + 93 per hit (3 hits)" (Templar Pummel; likewise 13 Gladiator, 10 Spiritmaster, 5 Sorcerer incl. Hellfire and Firestorm, 4 Templar, 3 Ranger skills), and the aion2t page's flat token for Pummel is "93-93", the per-hit number, so ratio and flat are both per hit and a cast deals N times one hit. Texts with no "per hit" ("Deals 58-58 damage (2 hits)", Assassin and Chanter) give one whole-cast number and are not multiplied. Rule: `damage.per_hit_multiplier`; DoT ticks are never multiplied. Tests pin Pummel 3 x (1195 + 93), Rending Blow 2 x (742.5 + 70), Rage Burst 5 x (2180 + 1327), and Quick Slice unchanged. Caveat: the Sorcerer numbers (Hellfire 2 hits, Firestorm 5 hits) were calibrated before this rule; the Sorcerer boss DPS rises from 3.9k to 10.5k, which is not validated against an in-game figure.
5. **Baseline profile.** Heart Gore (and any crit-triggered proc) never fired in v2 because `Stats()` has 0% crit, so no crit events exist. `models.BASELINE_L45_STATS` (attack +1.6%, combat speed +3.8%, CDR 0.1% from the DarthThot armory sample; crit 15% is an estimate, the sample shows +2.8% from attributes only) is used for validation and mirrored in the web manual-build defaults (`web/src/features/build/manualBuild.ts DEFAULT_STATS`). `Stats()` itself is unchanged (tests depend on it). The same profile is applied to every class.

## Reading it
- The stat-buff fix does what v2 predicted: Chanter picks Undefeated Mantra and Power of the Storm, Cleric picks Prayer of Amplification (4/4), Ranger picks Vaizel's Authority and Bow of Blessing, Gladiator picks Lunge Stance (and Zikel's under the baseline profile), Assassin Swift Contract. Lunge Stance, Zikel's, Vaizel's, Bow of Blessing, Benediction, Undefeated Mantra, Power of the Storm, Swift Contract and Prayer of Amplification all have a positive `_is_buff` value and a positive solo gain.
- Stigma overlap is noisy under the baseline profile: 3 to 4 slots are chosen greedily from about 30 candidates by a heuristic priority, and several slots end up as zero-gain fillers (Smoke Bomb, Ensnaring Mark, Tenaciousness). Differences of one pick between the two profiles are not a regression signal.
- Spiritmaster lost Flame Blessing and Corrode at default Stats: with higher Spirit damage (per-hit rule: Ancient Spirit 4 hits, Destructive Attack 5 hits) Destructive Attack and Siphon outrank them. That is the engine's valuation, not a recognition failure; Flame Blessing is now a recognised buff and has +2.8% solo gain.
- Templar rotation share fell (0.67 at the start of this task, 0.58 default, 0.33 baseline): Pummel and the Flash Rampage/Annihilate line are still not in the boss rotation; with the per-hit rule Pummel is worth more and the Templar agent's data wiring is the remaining item (open).
- Cross-class DPS is still not a tier list (Sorcerer 10.5k and Templar 6.0k vs Cleric 4.5k default); do not publish cross-class numbers. The per-hit rule raised every multi-hit class.
