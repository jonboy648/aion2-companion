# Aion 2 Daevanion window reference
Image: https://images.mein-mmo.de/medien/2026/09/Aion-2-Daevanion.jpg (saved %TEMP%\daev_ref\daev1.jpg)
Text sources: https://mein-mmo.de/en/aion-2-arkana-daevanion-pet-you-need-to-understand-and-master-these-3-systems,1589883/2/ ; https://thegameswiki.com/aion-2/wiki/daeva-system-and-daevanion-board
- Six boards (tabs): Nezekan Lv12, Zikel Lv20, Vaizel Lv30, Triniel Lv40, Ariel (PvE) Lv45, Azphel (PvP) Lv45.
- Board is one dark navy/black full-window background with faint thin circular arcs; no visible connector lines.
- Nodes are a square grid of small SHIELD/crest-shaped tiles with a metallic grey-gold bezel and a gold rune glyph.
- Colour by type/cost: grey = base stat (1pt), green = passive (2pt), blue = active skill level (3pt), orange = unique/percent (4pt, big orange fill).
- Start node sits in the centre: a larger blue-teal crest with a gold square frame.
- Orange nodes sit at the board corners/edges; blue and green are scattered between grey ones.
- Unlocked (selected) nodes appear lit (bright glyph, glow); unreachable ones are dimmer.
- Grid is sparse: gaps where no node exists; adjacency is orthogonal.
- Points: each node costs 1-4 points, spent from a Daevanion point pool shown by the window.
